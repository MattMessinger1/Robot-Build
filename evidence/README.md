# Experiment evidence

When physical testing begins, keep each run in its own folder under `evidence/runs/`, named with a date and run ID. Include the setup and board details, servo model and supply, sensor orientation, calibration and zero, code version, raw timestamped readings, independent protractor observations and their precision, and notes on errors or failed runs. Keep useful setup photos, analysis, and copies of the original earlier results with the records. Preserve the originals where they are. Link each sample ID to its reference observation.

Keep sensor readings and any pretend or changed readings clearly labeled and separate. Preserve original inputs and identify changed copies.

Both `evidence/runs/` and `logs/` are ignored by Git. They remain local and will not appear in another person's clone. Keep an additional copy in a location you control, and agree separately on a suitable place to share the evidence with collaborators. Review any files before sharing; this repository is public. Do not put credentials or private information in it.
