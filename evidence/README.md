# Experiment evidence

When physical testing begins, keep each run in its own folder under
`evidence/runs/`, named with a date and run ID. Include the setup and board
details, calibration and zero, code version, raw timestamped readings,
independent marked-angle observations and their precision, photos or video,
analysis, and notes on errors or failed runs. Label altered copies and preserve
the originals. Link each sample ID to its reference and photo.

Run folders are ignored by Git so they are not uploaded accidentally. Local
cloud files alone may not be durable: keep an additional copy in a location you
control. Decide which evidence to share before adding it to Git.
